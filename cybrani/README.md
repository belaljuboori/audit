# Cybrani

Cybrani is a project-based eLearning platform: a course catalog, enrollment, a
student dashboard, and a lesson player with video/reading/quiz lessons and
progress tracking.

Built with Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui-style
components, Prisma + SQLite, and cookie-based session auth (bcrypt + signed
JWT via `jose`).

## Getting started

```bash
npm install
cp .env.example .env   # fill in AUTH_SECRET with a random string
npm run db:push        # create the SQLite database from prisma/schema.prisma
npm run db:seed        # seed demo courses, lessons, and a demo user
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Demo login: `demo@cybrani.com` / `password123` (pre-enrolled in a few courses
with partial progress, seeded by `prisma/seed.ts`).

## Project structure

- `src/app/(marketing)` — public site: landing page, course catalog, course
  detail pages.
- `src/app/(auth)` — login and signup.
- `src/app/(app)/dashboard` — signed-in student dashboard.
- `src/app/(app)/learn/[slug]` — the course player (lesson sidebar, video /
  reading / quiz lessons, progress tracking).
- `src/lib/data` — Prisma read queries.
- `src/lib/actions` — server actions (auth, enrollment, lesson/quiz progress).
- `src/proxy.ts` — route protection for `/dashboard`, `/learn`, `/login`,
  `/signup` (Next.js 16 renamed `middleware.ts` to `proxy.ts`).
- `prisma/schema.prisma` / `prisma/seed.ts` — data model and seed data.
- `design-system/cybrani/MASTER.md` — the design system (colors, type,
  UX rules) generated by the `ui-ux-pro-max` skill and used to build this UI.

## Scripts

- `npm run db:seed` — reset and reseed demo data
